# Validação

- Flutter analyze: sem problemas.
- Flutter test: oito testes aprovados.
- Build release para o caminho /quadra/: aprovado, sem CDN de recursos.
- Lógica: todas as oito grades têm solução única; pistas, desfazer/refazer, dicas, pausa e restauração validados.
- Widget: larguras de 320, 390, 768 e 1280 px, inclusive grade 9×9, sem exceção de layout; conclusão e conquista verificadas.
- Navegador: marcação por clique e teclado, setas, desfazer/refazer, pausa, erro intencional, verificação, dica, conclusão e persistência após recarregar.

Os testes não equivalem a uma auditoria com todos os leitores de tela. O armazenamento é local, sem sincronização entre dispositivos.
